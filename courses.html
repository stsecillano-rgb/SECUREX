Hardware and Software Explanations

These two ideas appear in almost every platform security lesson.

Hardware

Hardware refers to the physical components of a computer or computing platform that can be physically touched.

Examples: CPU, RAM, Motherboard, Storage, Network Interface Card, and Input/Output devices.

Hardware provides the physical foundation where software and operating systems run.

Software

Software refers to programs and instructions that tell computer hardware what to do.

Examples: Operating Systems, Applications, Drivers, Utilities, and Security Software.

Software controls and uses hardware resources to perform tasks.
